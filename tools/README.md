# Herramientas de Extracción & Respaldo de Datos (Tools)

Este directorio contiene las herramientas y respaldos utilizados para la extracción de información del sitio original y compilación de datos académicos:

- `scrape_giovanni.py`: Script de scraping autónomo en Python (biblioteca estándar) que extrae las 10 páginas del sitio original, procesando metadatos e imágenes.
- `generate_dataset.py`: Compilador de dataset original a TypeScript.
- `data_raw/`: Directorio de respaldo de imágenes originales, páginas en markdown y archivo `site_data.json`.
